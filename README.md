# 애프터이펙트 2027 완전 실습 — 기본기부터 AI 협업까지

안지아 지음 · 2027 EDITION (2026.11) · After Effects 27.0 · Higgsfield Plugin v1.0.64 · Claude(Higgsfield MCP / Bridge) 기준

애프터이펙트 한 가지 프로그램을 처음부터 끝까지 다루는 실습 교본의 원고와 실습 자료입니다. 앞의 절반은 기본기·모션그래픽·익스프레션·합성·3D이고, 뒤의 절반은 힉스필드 플러그인 패널, Claude 브리지, 애펙 자체 AI(AI Assistant, Object Matte)를 실습합니다.

**책 읽기: [`book/AE_2027_AI_Workbook.pdf`](book/AE_2027_AI_Workbook.pdf)** (123쪽, 182 × 257mm)

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `book/` | 책 PDF, HTML 원고(`book.html`), 책에 실린 그림(`img/`), 조판 스크립트(`build/`) |
| `project/` | 실습 애펙 프로젝트 `AE_2027_workbook.aep`와 컴포지션 안내 |
| `expressions/` | 책에 실린 익스프레션 전체 `all_expressions.js` (장·절 순서, 주석 포함) |
| `prompts/` | 책에 실린 Claude·힉스필드 프롬프트 전문 |
| `sources/` | 실습 영상·이미지 목록 `manifest.csv` (책의 장, 생성 모델, 설정, 크레딧, 프롬프트 요약, 주소) |
| `captures/` | 표기를 넣기 전의 화면 캡처 원본 |
| `diagrams/` | 도식(SVG)을 만든 파이썬 코드 |
| `log/` | 실제 작업 기록 — 순서, 오류와 해결, 크레딧 |

## 실습 비용

전체 실습과 도판 제작에 힉스필드 크레딧 약 238을 썼습니다(Ultra 플랜, 1,510.04 → 1,272.15, 2026.11.23). 항목별 기록은 책 25장의 표와 `log/작업기록.md`에 있습니다.

## 만든 방법

실습과 화면은 2026년 11월 22~23일, 저자의 지시에 따라 Claude가 Windows PC의 애프터이펙트를 직접 조작해 만들었습니다. 컴포지션과 레이어는 힉스필드 브리지로, 메뉴 선택과 화면 캡처는 Claude의 컴퓨터 사용 기능으로, 실습 영상과 도판 사진은 힉스필드의 생성 모델로 만들었습니다. 로그인과 결제, 내용 판단과 검수는 사람이 했습니다.

책 PDF는 `book/book.html`을 브라우저(Chromium)로 열어 인쇄한 것입니다. `book/build/paginate.js`가 쪽을 나누고 그림과 표를 배치합니다. 다시 만들려면 Playwright가 설치된 환경에서 `python3 book/build/render.py`의 경로를 고쳐 실행합니다.
