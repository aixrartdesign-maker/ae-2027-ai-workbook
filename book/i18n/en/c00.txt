[3] How to Use This Book
[4] This book covers one program, After Effects (AE for short), from start to finish. The first half is fundamentals, motion graphics, compositing and 3D; the second half shows three ways to add AI on top: the Higgsfield plugin panel, the Claude bridge, and AE's own AI.

[25] What Makes This Book Different
[26] <b>Every screen is real.</b> On 22–23 November 2026, on a single Windows PC, we installed AE 2027 (English) and Higgsfield plugin v1.0.64, and Claude clicked through the menus and captured each screen.
[27] <b>Real credits are recorded.</b> For every exercise we wrote down how many credits it used and how many minutes it took (Chapter 25).
[28] <b>What does not work is written down too.</b> Steps that AI could not do and a person had to do are marked “Your turn”.
[29] <b>Practice comes first.</b> You try it by hand first and the principles are summed up afterwards. Practice files and AE project files are in the GitHub repository (Appendix E).
