[836] 7-3 Shaking — wiggle
[837] <span class="lbl">EXPRESSION · Basic</span>wiggle(3, 30); // shake 3 times per second within 30 px
[838] <span class="lbl">EXPRESSION · One Axis Only (Position)</span>w = wiggle(2, 40);<br/>[value[0], w[1]]; // keep x, shake only y
[839] <span class="lbl">EXPRESSION · Gentle Camera Shake</span>wiggle(0.8, 12, 3, 0.5); // frequency, amount, octaves (detail), multiplier
[840] <span class="lbl">EXPRESSION · Looping Wiggle (for loops, 5 s cycle)</span>freq = 2; amp = 30; loopTime = 5;<br/>t = time % loopTime;<br/>w1 = wiggle(freq, amp, 1, 0.5, t);<br/>w2 = wiggle(freq, amp, 1, 0.5, t - loopTime);<br/>linear(t, 0, loopTime, w1, w2);

[863] 7-7 Bounce and Settle — Inertial Bounce
[864] The “follow-through” that overshoots slightly and comes back after stopping on a keyframe. Attach it to position, scale or rotation.
[865] <span class="lbl">EXPRESSION · A Ball Bouncing on the Floor (Position, 2 keys: start of fall · floor)</span>e = .7; g = 5000; nMax = 9;<br/>n = 0; if (numKeys &gt; 0){ n = nearestKey(time).index; if (key(n).time &gt; time) n--; }<br/>if (n &gt; 0){<br/>  t = time - key(n).time; v = -velocityAtTime(key(n).time - .001)*e;<br/>  vl = length(v); vu = (vl &gt; 0) ? normalize(v) : [0,0];<br/>  tCur = 0; segDur = 2*vl/g; tNext = segDur; nb = 1;<br/>  while (tNext &lt; t &amp;&amp; nb &lt;= nMax){ vl *= e; segDur *= e; tCur = tNext; tNext += segDur; nb++; }<br/>  if (nb &lt;= nMax){ delta = t - tCur; value + vu*delta*(vl - g*delta/2); } else { value; }<br/>} else value;
